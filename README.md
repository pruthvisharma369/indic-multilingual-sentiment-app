# Indic Sentiment App

A multilingual sentiment analysis web application built using Flask and Hugging Face Transformers. The application predicts whether a given text expresses Positive, Negative, or Neutral sentiment across multiple Indian languages.

## Features

- Multilingual sentiment analysis
- Supports multiple Indian languages
- Flask web application
- Modern and responsive UI
- Sentiment history
- Fast prediction using Transformers

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Hugging Face Transformers
- PyTorch
- SQLite
