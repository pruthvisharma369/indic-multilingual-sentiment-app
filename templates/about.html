About This Project

Indian Multilingual Sentiment Analysis using IndicBERT

A Master's project applying transformer-based NLP to sentiment classification across 12 major Indian languages — built to work natively in each language, without routing text through machine translation first.

The Model

What is IndicBERT?

IndicBERT is a transformer-based language model pretrained on large volumes of text across India's major languages. Unlike models trained primarily on English, it learns the vocabulary, grammar, and script patterns of languages such as Hindi, Tamil, Bengali, Telugu, and others directly.

For this project, IndicBERT is fine-tuned on a labeled sentiment dataset, teaching it to map its general language understanding onto a specific task: deciding whether a sentence expresses a Positive or Negative sentiment.

Pretrained, then fine-tuned

General language understanding first, task-specific sentiment classification second.

Multilingual by design

Trained across many Indian languages at once, rather than one model per language.

Task-focused output

Returns a label, a confidence score, and full class probabilities for every prediction.

Under the Hood

How transformers understand language

IndicBERT is built on the transformer architecture — the same family of models behind most modern NLP systems.

Self-attention

Each word looks at every other word in the sentence at once, learning which ones matter most for understanding its meaning in context.

Encoder architecture

Stacked encoder layers build up a rich representation of the full sentence, rather than reading it strictly left to right.

Fine-tuned head

A classification layer sits on top of the transformer, converting its language understanding into a Positive/Negative sentiment prediction.

Pipeline

Project workflow

From raw text to a stored, searchable prediction — here's how a single request moves through the system end to end.

1

Language selection

The user selects which of the 12 supported languages their text is written in.

2

Text input

The sentence is typed or pasted into the Analyze page and sent to the backend.

3

Tokenization

IndicBERT's tokenizer breaks the sentence into sub-word tokens the model can process.

4

Model inference

The fine-tuned IndicBERT model predicts a sentiment label with class probabilities.

5

Storage & display

The result is saved to SQLite and rendered on the Result page, ready to revisit from History.
